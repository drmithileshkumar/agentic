4 Minimum Viable Tactic Set

1 Why a restricted set at all

The harness (agents/first_e2e_test.py) already makes a real design decision on this: its system prompt explicitly bans ring, omega, simp, aesop, tauto, and decide, instructing the model to “prove this step by step using intro/rw/exact/apply/calc instead, so the proof trace is actually informative for the study.”

The reason is specific to what this project studies. A decision procedure like ring or omega either closes a goal outright or fails — it gives no partial signal about which reasoning step was wrong. Since this project’s subject is hallucinations in the agent’s step-by-step reasoning, a tactic that swallows several reasoning steps into one opaque call is close to useless as data: a failure only says “the decision procedure didn’t apply here,” not anything about the agent’s own reasoning. This chapter makes that already-made decision explicit and generalizes it into a usable reference, rather than inventing a new policy.

2 The floor set

The following tactics, all drawn from the Tactic Cheat Sheet chapter (§3), are the ones needed to make progress on a goal one legible reasoning step at a time. Nothing here is a decision procedure; each one corresponds to a single, inspectable move.

Category

Tactics

Role

Structural

intro, exact, apply, have, rfl, constructor, use

Open and close goals directly; no search or automation

Rewriting

rw [h], rw [← h], nth_rewrite

Replace one term with another, named explicitly by the agent

Case analysis / induction

cases, induction, rcases, obtain

Split a goal on structure; every branch stays visible

Equality & structuring

calc, symm, trans, congr

Chain justified steps explicitly

Logic / contradiction

by_contra, by_cases, exfalso, push_neg, left, right

Restructure the goal without deciding it

Goal management

· (focus), <;>

Sequence and scope tactics across multiple goals

3 Explicitly excluded

Banned by the harness today: ring, omega, simp (all variants: simp_all, simp only, simp?, simp at), aesop, tauto, decide.

Not currently referenced by the harness’s ban list, but the same family of decision procedure for the same reason — excluded here too, pending explicit reconsideration: ring_nf, field_simp, linarith, nlinarith, polyrith, native_decide.

4 Undecided

  • norm_num, norm_cast, push_cast — narrower than simp, but still automated lemma search rather than a single named step. Not yet run against a real goal in this project, so not yet placed on either list.

  • dsimp — unfolds definitions only, no lemma database; arguably closer to the floor set than to simp despite the name. Same status: undecided until it’s actually needed.

5 Discovery and debugging tools — not proof steps

sorry, #check, #eval, exact?, apply?, simp?, #loogle/#leansearch/#statesearch are all tools a human uses while writing or debugging a proof. None of them are tactics an agent should ever propose as a logged step: sorry admits the goal without proving it (exactly the kind of silent failure this study needs to catch, per the Tactic Cheat Sheet’s gotchas section), and the ?-suffixed tools search the library rather than performing an inspectable reasoning step themselves.
